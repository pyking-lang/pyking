


# Pyking for Experienced Programmers

Welcome to Pyking! In this short tutorial, you will learn how to use and program with Pyking. This tutorial is aimed at people who are already experienced in programming in one or more other languages. Hence, it will not teach how to program, but rather how Pyking works and how it is different from other languages.


Pyking was developed as an educational project at KTH Royal Institute of Technology to make it easy for beginners to learn different programming concepts, techniques, and paradigms. The language is easy to use and has a syntax largely inspired by Python; thus, the "py" in Pyking. However, the language is statically typed, with many features such as algebraic data types, accumulator loops, and more. This short tutorial gives a quick overview of its features.

## Hello world and running a program

The classic Hello World program

``` pyking
print("Hello", "world", 2026)
```

Print statements behave and look like Python print statements: several arguments are concatenated with a space in between, and printed to standard output with a trailing new line. 

If you read this document in a markdown viewer, you cannot run the program, but if you open it up in Pyking notebook, you can read and run directly in the web browser. Either click "run" or use shift-enter when inside the edit window.
