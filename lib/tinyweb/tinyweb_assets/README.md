# Samples shipped with tinyweb

`kick1.wav`, `snare1.wav`, `hihat1.wav` and `piano_c1.wav` are CC0
(public domain) recordings from [freesound.org](https://freesound.org).
`tinyweb.load_sample` finds them by name when the page has no file of
that name beside it.

`ball.png`, `star.png` and `tile.png` are pictures drawn for tinyweb and
given to the public domain (CC0). `tinyweb.load_image` finds them by
name when the page has no file of that name beside it.
