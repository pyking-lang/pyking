#Exercises and quizzes

A cell's input can be written on its header:

import io
import sys
print("hello", io.read_line(), sys.args())

So can a read-only cell's, an error cell's and a fragment's:

import io
print(int(io.read_line()) * 2)
x = 1
x := 2
def f(x): ...

The older way still works, a ```stdin block right before the cell:

import io
print("hi", io.read_line())

An output shown as if the cell had run:

print("my out")

Output checked in test mode but not shown, with the input it is read from, and what debug writes:

import io
debug("to stderr")
